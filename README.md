## 这是什么

349 个 Android 自由/开源应用索引的**重组版**（原 37 分类 → 3 条主线）。原作者立场鲜明：Google/Apple/Meta 之外存在一个完整世界。Lunarwave 重组视角：这份清单在 AI 时代有了新的战略含义——**数据主权**。

## 三条主线

### 主线 A · 去 GMS 化（框架层）
Framework/Services 类——替代 Google Play Services 与推送通知的自治方案。
> AI 时代增量解读：每少一个 Google 依赖，就少一份被 AI 数据采集的暴露面。

### 主线 B · 日常替换（应用层）
Communication（IM/邮件/协作）→ Browser → Keyboard → Launcher → Gallery/Music/Notes → File Manager。日常高频入口全部可换 FLOSS，隐私成本趋近于零。

### 主线 C · 主权与自持（数据层）
Self-hosting（自托管文件与服务）+ Backup + Security/Privacy + Finance（含加密货币）。
> **Lunarwave 核心增量：Self-hosting 是 AI 时代 FLOSS 的价值锚点**——当云端 AI 都在吸数据时，自托管 = 让 AI 只能碰你同意它碰的数据。

## AI 时代选购动线（Lunarwave 增量排序建议）

1. **先换 Framework 层**（数据暴露面最大）
2. **再换日常应用**（高频入口）
3. **最后上自托管收尾**（数据主权闭环）

垂直类（教育/健康/导航）为「按需查」第三梯队。
